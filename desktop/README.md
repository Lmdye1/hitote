# ひとて Desktop — 普通のキーボードで片手日本語入力

Windows用の常駐ソフトです。物理キーボードの左側をかなの「行＋母音」の2打鍵に割り当て、入力先のアプリへローマ字キーを送ります。日本語変換はWindowsのIMEに任せます。

## 起動と使い方

1. `start.cmd` または `bin\Hitote.exe` をダブルクリックします。起動時は **OFF** です。
2. メモ帳など入力先のアプリを開き、入力欄をクリックします。
3. 日本語IMEを **ひらがな・ローマ字入力** にします。
4. **F2** で片手入力をONにします。
5. 行のキーを押し、続けて **A / S / D / F / G** で「あ / い / う / え / お」の段を選びます。
6. **Space** で漢字変換・次の候補、**F または Enter** で確定します。
7. **F2** を押すと通常入力に戻ります。

例：「きょう」なら `W S`（き）→ `X G`（よ）→ `B`（ょへ変更）→ `Q D`（う）→ `Space`（変換）→ `F`（確定）。

## キー配列

| 行キー | A | S | D | F | G |
| --- | --- | --- | --- | --- | --- |
| Q | あ | い | う | え | お |
| W | か | き | く | け | こ |
| E | さ | し | す | せ | そ |
| A | た | ち | つ | て | と |
| S | な | に | ぬ | ね | の |
| D | は | ひ | ふ | へ | ほ |
| Z | ま | み | む | め | も |
| X | や | （ | ゆ | ） | よ |
| C | ら | り | る | れ | ろ |
| V | わ | を | ん | ー | 〜 |

| キー | 動作 |
| --- | --- |
| F2 | 片手入力ON/OFF。起動中はこのキーを切替に使用 |
| Space | IMEの変換・次候補。通常のSpace操作をそのまま渡す |
| F / Enter | 確定・改行。Fは行を選択していないときのみ |
| R / Backspace | 1文字削除。行の選択途中なら行選択をキャンセル |
| T | 直前に入力したかなの濁点・半濁点。は→ば→ぱ→は |
| B | 直前に入力したかなを小文字に。つ↔っ、や↔ゃなど |
| G / H | 読点・句点。Gは行を選択していないときのみ |
| Escape | 行選択をキャンセル。行選択中でなければアプリに渡す |

Ctrl / Alt / Shift / Win を押しながらの操作は通常のキーボードとして扱います。小文字・濁点は、文字を入力した直後、変換やカーソル移動の前に操作してください。

## 常駐・終了

- ウィンドウの×や「通知領域にしまう」でガイド画面を隠します。
- 通知領域の「ひ」アイコンは **緑＝ON、灰色＝OFF** です。ダブルクリックでガイドを開きます。
- 終了はアイコンを右クリックして **終了**。終了するとキーフックを解除します。
- 自動起動・レジストリのキー配列変更・入力履歴の保存は行いません。

## 対応範囲

- 日本語IMEの **ひらがな・ローマ字入力** を前提にしています。IMEがOFFの場合はローマ字が入り、濁点・小文字の置換も正しく動作しません。
- 濁点・小文字は、未変換の直前1文字をBackspaceで消して入れ直します。マウスクリック、カーソル移動、変換、ショートカット、ウィンドウ移動後はこの操作対象をリセットします。
- IME設定によって記号の見た目や変換動作が異なることがあります。
- 管理者権限で起動したアプリや、キー送信を受け付けないアプリへの入力には対応しない場合があります。送信エラーを検出したら片手入力をOFFにします。
- 現在は左手配列の試作品です。

## 開発

Windows付属の .NET Framework のC#コンパイラでビルドします。追加パッケージはありません。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

`InputEngine.cs` が配列と状態遷移、`KeyboardService.cs` がフックとキー送信、`Program.cs` がガイドと通知領域のUIです。
